# Agentic SOC backend

FastAPI and LangGraph service for Agentic SOC. It owns connector ingest, OCSF
normalisation, correlation, risk scoring, governed investigation, deterministic case
decisions, state repositories, audit, and the single cost-ledgered model gateway.

Start with the repository [README](../README.md), then use
[DEPLOY](../DEPLOY.md) for deployment and [the Help Center](../docs/index.md) for
operator and API guidance. The standalone Console in `../webui/` is the primary user
interface.
