## D. Canonical `GET /api/metrics/noise-reduction` contract (both ★a and ★b bind to THIS)
```
{ window_hours:int, generated_at:iso,
  bands:['critical','high','medium','low','info'],
  stages:[ {key, label, source:'counters'|'cases', deterministic:bool, total:int, by_severity:{band:int}} ]
    for keys: ingested → clustered → cases → auto_cleared → escalated → needs_human,
  drops:{suppressed:int, ignored:int},
  reduction:{ overall_pct:number|'—', human_reduction_pct:number|'—' },   // headline "Noise reduced by N%"
  counters:{ available:bool, since:iso|null, incomplete:bool },            // partial state when counters warming up
  cases_meta:{ truncated:bool, store_total:int, fetched:int } }
```
`ingested/clustered` come from durable `noise_counters` (by severity band); `cases`+outcomes from `quality_metrics()`-style tally.
MECE outcome order so bars sum: needs_human > escalated > auto_cleared(FP, decision_by==agent) > true_positive. `available:false`+null ingested = honest "counters warming up" → UI degrades to case-only funnel.
